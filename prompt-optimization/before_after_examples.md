# Prompt Optimization Examples

## Example 1: Weak Prompt

Explain sepsis.

## Improved Prompt

You are a critical care nurse educator.

Explain sepsis to a nursing student using simple language.

Include:

* Definition
* Common causes
* Warning signs
* Why early treatment matters
* One short example

---

## Example 2: Weak Prompt

Summarize this note.

## Improved Prompt

Summarize the following ICU clinical note in fewer than 150 words.

Preserve:

* Diagnosis
* Vital signs
* Abnormal findings
* Current treatments
* Immediate risks

Do not add information that is not present in the note.

Clinical note:
[Insert note]

---

## Example 3: Weak Prompt

Make this professional.

## Improved Prompt

Rewrite the following message in a professional tone while preserving the original meaning.

Requirements:

* Keep it concise
* Avoid overly formal language
* Do not add new information

Message:
[Insert message]
