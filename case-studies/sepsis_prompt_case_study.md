# Prompt Engineering Case Study: Sepsis Explanation

## Objective

Improve the quality of an AI-generated explanation about sepsis using prompt engineering.

## Original Prompt

Explain sepsis.

## Problem

The prompt is too broad. It does not specify:

* Audience
* Level of detail
* Desired structure
* Safety considerations
* Output format

## Improved Prompt

You are a critical care nurse educator.

Explain sepsis to a nursing student in simple terms.

Include:

1. Definition
2. Common causes
3. Early warning signs
4. Why it can become life-threatening
5. Why urgent treatment matters

Use clear headings and avoid unnecessary jargon.

## Expected Improvement

The improved prompt should produce a response that is:

* More structured
* Easier to understand
* Clinically safer
* Better suited to the intended audience
* More useful for training and education

## Skills Demonstrated

* Prompt refinement
* Healthcare communication
* AI safety awareness
* Audience-specific writing
* Clinical reasoning
